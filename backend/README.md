# How to Run Backend (Custom CMS)

## 1. Start the Server
```bash
cd backend
npm run dev
```
*(Alternatively, run `npm start`)*

## 2. Open in Browser
Navigate to:
```
http://localhost:8080/admin/
```

- **Clearance Passcode:** `Greenovation@2026!`
- **Health Endpoint:** `http://localhost:8080/api/health`
